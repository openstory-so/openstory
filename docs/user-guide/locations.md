A location is a place your stories happen in: a kitchen, a street corner, a spaceship bridge. Every location belongs to your team. A sequence does not keep its own copy. It uses the team's location, so the same kitchen looks the same in every episode.

## Your team's locations

**Locations** in the main navigation lists every location your team has, most recently used first. Open one to see its details, its reference image and its photos.

You can make a location there before there is a script. Give it a name and say what it is rendered as. Add photos if you have them.

## Locations in a sequence

The **Locations** tab of a sequence shows the places that sequence uses. They get there in three ways:

- **From the script.** Script analysis finds the places your script names and makes a location for each, with a reference image.
- **Picked before you generate.** On the new-sequence screen, click the location icon and pick from your team's locations. When the script has a matching place, the sequence uses the one you picked. Nothing is copied and no new image is drawn.
- **Replace.** On a location in the sequence, **Replace** swaps it for another of your team's locations. Every scene set there now uses the other place, and the shots set there are rendered again. The replacement needs a reference image first.

Removing a location from a sequence does not delete it. It stays in your team's locations.

## Details

| Property                | Description                                                           |
| ----------------------- | --------------------------------------------------------------------- |
| **Name**                | Location name                                                         |
| **Type**                | Interior, Exterior, or both                                           |
| **Description**         | Detailed setting description                                          |
| **Architectural Style** | Building and structural aesthetic                                     |
| **Key Features**        | Notable visual elements                                               |
| **Ambiance**            | Overall mood and atmosphere                                           |
| **Rendered as**         | What the place is drawn as, such as "Photoreal live action". Required |
| **First Appears**       | Where the location first appears in this sequence's script            |

Lighting, time of day and colour belong to each scene, not to the location.

An edit changes the location everywhere. Other sequences that use it show their shots as out of date, and update them when you ask.

## Reference image

Each location has one reference image. It anchors every shot set there, in every sequence. You can generate it again, upload your own, or go back to an earlier version.

The image follows **Rendered as**, not a sequence's style. A sequence's palette and mood are applied at the shot.

## Photos

Upload any number of photos of the place. The reference image is drawn from all of them. Adding or removing a photo makes the reference image out of date until it is drawn again.

## Deleting a location

A location can be deleted from your team only when no sequence uses it, archived sequences included. Remove it from those sequences first. The message that follows a delete has **Undo**.
